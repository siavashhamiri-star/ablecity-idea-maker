# ایده‌ساز توانا | TAVANA IdeaMaker

## درباره پروژه

**TAVANA IdeaMaker** یک استودیوی موبایل‌محور برای تبدیل ایده‌های متنی به محصولات دیجیتال است.

کاربر ایده خود را وارد می‌کند و سیستم آن را به یک ساختار قابل‌ویرایش تبدیل می‌کند؛ سپس می‌تواند محصول را مشاهده، آزمایش و خروجی بگیرد.

## مسیر اصلی

IDEA → FEASIBILITY → SPEC → MANIFEST → RENDER → PREVIEW → TEST → EXPORT → ARTIFACT

## اصل معماری

Manifest تنها منبع حقیقت (Single Source of Truth) پروژه است.

AI مستقیماً کد نهایی تولید نمی‌کند؛ در صورت استفاده، فقط Manifest را ایجاد یا ویرایش می‌کند.

## قابلیت‌های MVP

- ساخت پروژه وب از Manifest
- اعتبارسنجی Manifest
- Migration برای نسخه‌های مختلف Schema
